# Utrust Clothing Tanzania Limited

Official B2B digital portal and industrial landing page for **Utrust Clothing Tanzania Limited** — Tanzania's largest industrial textile mill based in Dar es Salaam.

Built with **Astro**, **React**, and **Tailwind CSS**, optimized for lightning-fast delivery across African mobile networks (3G/4G) and designed for zero-latency deployment on **Cloudflare Pages**.

---

## ⚡ Tech Stack

- **Framework**: [Astro v5](https://astro.build/) (Static Site Generation / Island Architecture)
- **UI & Islands**: [React 19](https://react.dev/) + [Lucide Icons](https://lucide.dev/)
- **Styling**: [Tailwind CSS v3](https://tailwindcss.com/)
- **Hosting**: [Cloudflare Pages](https://pages.cloudflare.com/) (Edge cached in Dar es Salaam & Nairobi)
- **Internationalization (i18n)**: English (EN), Kiswahili (SW), and Chinese (ZH)

---

## 🚀 Cloudflare Pages Deployment Settings

When connecting this repository to Cloudflare Pages:

| Setting | Value |
| :--- | :--- |
| **Framework preset** | `Astro` |
| **Build command** | `npm run build` |
| **Build output directory** | `dist` |
| **Root directory** | `/` |
| **Node.js Version** | `22` (or >= 18) |

## 💻 Local Development

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build

# Preview production build locally
npm run preview
```
